# Аудит возможности застрять — v0.53.0

## Обнаруженные и исправленные затыки

### Пустой рабочий стол при ненулевой очереди — скрин v0.51.0

Джуну доступны bug/feature. После их завершения в общей очереди остаются review/debt/support, которые ещё закрыты по самостоятельности. `RemainderQueue` правильно скрывал их, но счётчик показывал три задачи, а `TaskStartButton` скрывался с причиной «сначала выбери». В результате экран не объяснял отсутствие выбора.

Теперь счётчики ноутбука и офиса показывают доступную личную очередь. Пустой стол объясняет ограничения, указывает следующие события команды и предлагает закончить день. При завершении дня очередь переносится; утром есть встреча и доступная работа. Позднее время и обязательный разговор о работе также имеют объяснение. Разговор с руководителем доступен прямо на столе, без поиска скрытого экрана.

### Старый рабочий этап без следующего действия

Миграция могла сохранять заглушку `actionHistory=['resume']`. Она не соответствует действию графа, поэтому доступных действий не было. Заглушка очищается при загрузке, исходные наблюдения и флаг уже оплаченного этапа сохраняются. Неизвестная старая кнопка больше не создаёт эту заглушку.

## Проверенные маршруты выхода

| Состояние | Продолжение |
| --- | --- |
| Утренний sync не завершён | Перейти к встрече команды |
| Есть собственная задача | Продолжить её в приложении ноутбука |
| Доступные задачи выполнены, остались закрытые по грейду | Объяснение, событие команды или конец дня |
| Новую задачу уже поздно начинать | Объяснение времени, завершение дня |
| Обязательный performance review | Ответить руководителю на рабочем столе |
| Коллега ещё готовит ответ | Локальная работа, пауза и другая задача, либо новый рабочий день |
| Задача на паузе | Возобновить тот же запрос и наблюдения |
| Прогулка или доставка | Прежние явные возврат/закрытие, покрытые регрессиями |
| Рутинный период | Прежний выход из сводки; перенос очереди покрыт тестами |
| Завершение карьеры | Прежний архив и начало новой карьеры |
| Найм преемника | Новый экран итогов, затем выбор и подтверждение героя |

Это аудит модели и автоматических прохождений, а не гарантия отсутствия любого возможного повреждённого сохранения. Скрин воспроизведён отдельным тестом: день 50, 11:57, выполненные bug/feature и три закрытые задачи. Проверены состояние, объяснение на русском/английском и переход конец дня → сон → следующая утренняя встреча. Длинные карьерные прогоны и семь семейств задач продолжают проходить.

## Экран победы и Новая игра+

Кнопка найма на доступном лидерском уровне сначала показывает итоги. Просмотр ничего не архивирует и не переключает героя; можно продолжить прежней командой. «Новая игра+» открывает выбор профессии. Только окончательный найм фиксирует карьеру и передаёт тот же мир следующему герою.

Статистика: реально завершённые задачи, календарные игровые дни, сыгранные дни, минуты в видимом окне игры, реальные полные сутки с начала нового прогона. Достижения — фактические исправления, ревью, проверенные делегирования, открытые понятия и повышения. Просмотр итогов и подтверждение найма отдельно сохраняют время; новый герой начинает собственный отсчёт.

Таймер учитывает видимое окно с фокусом, не промежутки с закрытой/скрытой игрой. Фоновая вкладка не считается. Обновление каждые 15 секунд и при действиях; таймер не влияет на баланс или игровое время. Для старого сохранения неизвестный старт обозначен явно, минуты собираются только после обновления. Архив сохраняет время завершённого героя.

Проверка завершена: 345 тестов в 56 файлах проходят; production build успешен. Через браузер проверены новый счётчик рабочего стола и кнопки следующего события/завершения дня. Экран победы проверен рендером на двух языках и переходом найма в тестах.
