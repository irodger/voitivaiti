# Войти Вайти — v0.21.0

Продолжение профессионального содержания по аудиту v0.13.0: 18 из 22 профессий, 54 сочетания роли и проблемы после стартовых задач.

## Изменения

Системный администратор сопоставляет доступность сервиса, учётную запись и назначенные группы. Перезапуск тестового сервиса даёт наблюдение: соединение восстановилось, отказ остался. Можно сравнить другую тестовую запись, подготовить узкий временный доступ или изменение группы с проверкой отзыва. Рабочие права не объявляются изменёнными после проверки тестовой записи.

Security Engineer сопоставляет обезличенные журналы и границу защиты. Более строгое правило на копии может остановить обычного пользователя; исследование продолжается с сохранёнными примерами. Можно проверить минимально нужные данные расследования, подготовить точечное ограничение или правило по состоянию операции. Проверяются разрешённый путь и запрещённое действие; результат не обещает полной защищённости и не выдаётся за выпуск правила.

Обе роли вносят preparation без фиктивного repair. Проверка на тестовых данных не уменьшает технический долг сама по себе; общие эффекты завершения задачи сохранены. Исследование сохраняется после reload. Первые сценарии, экономика и UI не менялись.

## Проверка и ограничения

197 тестов в 23 файлах, production build и проверка пробелов прошли. Проверены шесть новых сочетаний, обе ветки, неудачные действия, дополнительные наблюдения, reload и отсутствие фиктивного исправления продукта.

Браузерный прогон не проводился. Четыре профессии ещё требуют расширения. Общий трёхшаговый каркас сохраняется; разнообразие длинной игры требует отдельного прогона. Сборка сохраняет предупреждение о размере основного файла более 500 kB.
