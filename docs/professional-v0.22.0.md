# Войти Вайти — v0.22.0

Продолжение профессионального содержания по аудиту v0.13.0: 20 из 22 профессий, 60 сочетаний роли и проблемы после стартовых задач.

## Изменения

Project Manager собирает фактическое состояние, зависимости и доступное время. Новые оценки без изменения состава работ показывают незавершённую зависимость и открывают исследование. Можно уточнить вытесняемую работу, согласовать ограниченный объём или перестроить последовательность и срок. Исполнители и заказчик подтверждают план; оставшаяся работа не исчезает после согласования.

Delivery Manager отделяет успешную сборку от готовности выпуска. Исследует непроверенные сценарии, совместимость компонентов и условия остановки. Можно назначить владельца остановки, подготовить ограниченный выпуск или согласовать полный набор условий. Подтверждение готовности не объявляется уже доставленной версией.

Обе роли вносят preparation без фиктивного repair. Проверка плана не уменьшает технический долг сама по себе; общие эффекты завершения задачи сохранены. Дополнительные действия и наблюдения сохраняются после reload. Первые сценарии, UI и экономика не менялись.

## Проверка и ограничения

205 тестов в 23 файлах, production build и проверка пробелов прошли. Общие проверки охватывают шесть новых сочетаний и обе ветки; отдельные — неудачное действие, дополнительное исследование, reload и отсутствие фиктивного исправления.

Браузерный прогон не проводился. Solution Architect и Software Architect ещё требуют расширения. Общий трёхшаговый каркас сохраняется; проверка разнообразия длинной игры остаётся отдельной работой. Сборка сохраняет предупреждение о размере основного файла более 500 kB.
