# v0.28 — evidence with history

Recurring scenes and subsequent artifact scenes receive a snapshot of the latest encounter: its recorded outcome from problem history, remaining limitations and selected observations. A new condition follows the existing story change. The snapshot is stored in task.scene; later world mutations do not rewrite an active investigation or discovered records.

Review exposes the original passed case and the neighboring case absent from the report. Absence of evidence does not claim a failure. Comparing QA environments exposes different outcomes under a controlled environment change. Dependency/delegation replies inherit available role evidence, gated by the existing reply readiness check; requests never reveal a colleague result early.

The playtest helper now inspects required artifact records and compares them through the same actions as the interface rather than skipping evidence with a direct technical action. Existing direct transitions remain compatible.

Regression checks cover real prior outcome/limitations, immutable scene snapshots after reload, saved readings, colleague readiness and completion, review evidence, and the existing long career/world-story runs. No changes to numeric project effects, career pacing or economy.
