# Войти Вайти — v0.18.0

Продолжение профессионального содержания по аудиту v0.13.0. После двух стартовых задач собственные исследования доступны 12 из 22 профессий: 36 сочетаний роли и проблемы.

## Новые рабочие ситуации

QA Automation сравнивает успешный и упавший запуски, условия ожидания и данные. Повтор до зелёного результата не закрывает шаг: журнал падения остаётся основанием для исследования. Дополнительный запуск с задержкой даёт новое наблюдение. Можно явно ограничить автоматическое покрытие с ручной проверкой или сделать проверку воспроизводимой и подтвердить, что она ловит исходный сбой.

UX Research наблюдает самостоятельный путь человека. Вопрос о привлекательности экрана не объясняет остановку и открывает следующий исследовательский ход. Можно уточнить цель участника, передать ограниченное наблюдение или проверить объяснение с другим участником на прототипе. Успех прототипа не объявляется исправлением рабочего продукта.

Роли вносят validation и discovery соответственно, без присвоения repair. Проверка этих результатов не уменьшает технический долг; общие эффекты завершения задачи сохранены. Первые сценарии, UI и экономика не менялись.

## Проверка

173 теста в 23 файлах и production build прошли. Общие проверки охватили шесть новых сочетаний и обе ветки; отдельные проверки — ошибку, дополнительное исследование, reload и отсутствие фиктивного исправления продукта.

Браузерный прогон в этом проходе не проводился. Десять профессий ещё требуют такого же расширения. Общий трёхшаговый каркас сохраняется; долгосрочное разнообразие и интерес для человека без опыта в IT требуют отдельного игрового прогона.
