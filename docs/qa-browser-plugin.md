# Браузер OpenCode QA через локальный плагин

`.opencode/plugins/qa-browser/index.ts` использует API v2: `Plugin.define` из
`@opencode/plugin`, `ctx.tool.transform`, JSON Schema, `ctx.permission.assert`,
`ctx.session.hook('retry')` и cleanup из `setup`. Это не API v1. Автоматическое
обнаружение `.opencode/plugins/` не требует изменения глобального конфига или
установки пакетов. [API v2](https://opencode.ai/v2/docs/build/plugins),
[обнаружение плагинов](https://opencode.ai/v2/docs/plugins/).

## Запуск

Codex поднимает preview свежей сборки из корня проекта:

```powershell
npm run build
npm run preview -- --host 127.0.0.1 --port 4173 --strictPort
```

Плагин использует уже установленный Puppeteer и свой временный профиль Chrome.
Браузер Desktop не требуется. В Windows нужен разрешённый запуск OpenCode вне
ограничения на дочерние процессы Chromium; защита браузера не отключается.

| Инструмент | Ввод | Результат |
| --- | --- | --- |
| `qa_browser_open` | `{}` | Открыть фиксированный адрес; DOM и ID элементов |
| `qa_browser_state` | `{}` | Текст DOM и новые ID видимых элементов |
| `qa_browser_click` | `{ "element": "ID" }` | Нажать элемент; новое состояние |
| `qa_browser_type` | `{ "element": "ID", "text": "текст" }` | Заменить текст поля; новое состояние |
| `qa_browser_screenshot` | `{}` | PNG в артефактах; реальный путь |
| `qa_browser_errors` | `{}` | Ошибки страницы/консоли/сети и блокировки |
| `qa_browser_close` | `{}` | Закрыть браузер и профиль |

После state/click/type старые ID недействительны. DOM-снимок ограничен 14000
символами и 100 элементами; он не заменяет визуальную проверку. Контент страницы
считается данными, не инструкциями.

## Ограничения и завершение

- Только `http://127.0.0.1:4173/voitivaiti/`. Модель не передаёт URL, порт, JS,
  CSS-селекторы, shell или пути файлов. Фиксированные внутренние DOM-функции не
  являются инструментом выполнения произвольного JS.
- Навигация и запросы страницы за пределы origin/префикса блокируются, новые окна
  закрываются, downloads запрещены. Data-image допускается как ресурс, не навигация.
  Это ограничение инструментов, не отдельная сетевая песочница ОС.
- Ввод только в текстовые поля/textarea, до 512 символов. Нет upload, доступа к
  движку, store или localStorage.
- Разрешены только agent `qa` и permission `qa_browser` на фиксированный адрес.
  Edit deny и общий shell deny сохранены.
- PNG и actions.jsonl сохраняются только в автоматически созданных каталогах
  `e2e-artifacts/qa-browser/<хеш-сеанса>-<случайный ID>/`; пути нельзя задавать.
  Symlink/junction в родительских каталогах артефактов запрещён.
- Сеансы изолированы, максимум два браузера на экземпляр, операции последовательны.
  Закрытие: явное close, отмена инструмента, 2 минуты простоя, выгрузка плагина.
  Активная работа ограничена 10 минутами. Puppeteer удаляет свой временный профиль
  при закрытии; cleanup при принудительном аварийном kill ОС не гарантируется.
- Retry-hook для qa при HTTP 429 запрещает повтор и закрывает браузер этого сеанса.
  Для инфраструктурной пробы после 429 другие модели не вызываются. Обычный
  ограниченный fallback для отдельно запрошенного аудита остаётся в AGENTS.md.
- Codex после работы останавливает только свой preview.

## Детерминированная проверка без модели

При работающем preview:

```powershell
node --test --test-concurrency=1 scripts/qa-browser.test.mjs
```

Проверяются настоящие open/state/click/type/screenshot/errors/close, границы API,
устаревшие ID, изоляция, отмена, timeout/dispose и закрытие после ошибки провайдера.
Это проверка инфраструктуры Codex, а не действия языковой модели и не исследование
непокрытого игрового сценария.

Проверка загрузки плагина в установленном v2.0.30:

```powershell
& 'C:\Users\raxen\.opencode\bin\opencode.exe' api plugin.list --param 'location[directory]=C:/iRGames/VoitiVaiti'
```

DeepObject-параметр взят из OpenAPI v2. Первый ответ при отложенной загрузке может
быть пустым; проверяется конечный статус `voitivaiti.qa-browser: active`.

## Единственная модельная проба

Задание QA: open, прочитать состояние, screenshot before, нажать полученный ID
ENTER/ВОЙТИ, проверить появление полей создания персонажа, screenshot after,
errors, close. Не читать старые отчёты и не запускать стандартные npm-проверки.
Использовать подтверждённо бесплатную tool-capable модель, agent qa, явный title,
формат JSON. При 429 остановиться без дополнительных запросов.

Доказательство управления именно OpenCode — успешные tool_use в его выводе,
совпадающий журнал плагина и скриншоты. Статус active и детерминированные тесты
сами по себе не доказывают модельное выполнение. Отчёт должен различать эти факты.
