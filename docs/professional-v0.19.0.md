# Войти Вайти — v0.19.0

Продолжение профессионального содержания по аудиту v0.13.0: 14 из 22 профессий, 42 сочетания роли и проблемы после стартовых задач.

## Изменения

Системный аналитик прослеживает состояние операции между экраном, сервисом и хранилищем. Передача неоднозначного требования приводит к двум толкованиям и следующему исследовательскому действию. Можно уточнить владельца результата, описать временное правило или согласовать общий набор переходов, повторов и исключений. Проверка проходит по конкретным примерам; спецификация не объявляется готовым программным исправлением.

Бизнес-аналитик разбирает цель человека и процесс вместе с владельцем и поддержкой. Передача просьбы без уточнения цели показывает расхождение между выполненной просьбой и нужным результатом. Доступны уточнение ответственности, временный ручной путь или согласование критериев приёмки. Ограниченный путь оставляет нагрузку поддержки; общий результат готовит проверяемую задачу для реализации.

Обе роли вносят preparation без фиктивного repair. Проверка правил сама по себе не уменьшает технический долг; общие эффекты завершения задачи сохранены. Исследование, включая дополнительные действия, сохраняется при reload. Первые сценарии, экономика и UI не менялись.

## Проверка и оставшаяся работа

181 тест в 23 файлах, production build и проверка пробелов прошли. Проверены обе ветки всех шести новых сочетаний, неудачные действия, reload и отсутствие фиктивного исправления продукта.

Браузерный прогон в этом проходе не проводился. Восемь профессий ещё требуют расширения. Общий трёхшаговый каркас сохраняется; увеличение числа ролей не заменяет проверку разнообразия и интереса длинной игры.
