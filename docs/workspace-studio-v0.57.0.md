# Офис и ноутбук — v0.57.0

Рабочий экран связывает сцену офиса с карточкой «В фокусе сегодня» в правой панели. Карточка использует реальное состояние очереди, утренней встречи, текущей задачи, ожидания и конца смены. Прогресс берётся из завершённых этапов, ближайший шаг — из currentStepId. Переходы открывают ноутбук или экран команды без изменения игрового времени.

Подробная карточка не размещается под офисом: визуальная проверка показала, что это сжимает сцену. Под офисом сохранён компактный статус; персонажи и помещение получают прежнее пространство.

У каждого приложения ноутбука своя небольшая векторная иллюстрация: связи кода, запрос/ответ интерфейса, журнал событий, переписка. Иллюстрации декоративные и не изображают доказательства по задаче. Акцентные цвета берутся из токенов приложения. На экране справочного приложения видна его роль и доступен переход к реальному текущему шагу. В архивном просмотре этот переход не выдаётся за действие по прошлому этапу.

Проверены 375 тестов и production build, в браузере — офис, открытие ноутбука, справочное IDE и возвращение к рабочему Console. Для узкого экрана предусмотрено уменьшение иллюстраций и перенос кнопок; отдельного прогона на телефоне не было.
