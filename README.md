# Войти Вайти

Браузерная игра о карьере и жизни в IT-компании. Игрок знакомится с коллегами, решает профессиональные задачи, отвечает за последствия решений, развивается и отдыхает между рабочими днями. Компания и её история продолжаются при смене героя.

Доступны 22 профессии, русский и английский языки, обычный и взрослый режим реплик, интерфейс для компьютера и телефона. Инструменты рабочего устройства адаптируются к профессии.

[История изменений](CHANGELOG.md) · [Правила QA](docs/qa-workflow.md)

## Локальный запуск

Нужны Node.js 22.12+ и npm. Зависимости фиксируются в package-lock.json.

```sh
npm ci
npm run dev
```

Открой адрес из вывода Vite с базовым путём `/voitivaiti/`, обычно `http://localhost:5173/voitivaiti/`.

Для production-сборки:

```sh
npm run build
npm run preview
```

Preview использует содержимое dist; после изменений нужна новая сборка.

## Проверки и форматирование

| Команда                | Что делает                                                      |
| ---------------------- | --------------------------------------------------------------- |
| `npm test`             | Unit-тесты и проверки компонентов через Vitest                  |
| `npm run build`        | Проверка TypeScript и сборка Vite                               |
| `npm run test:e2e`     | Свежая сборка и полный браузерный набор Puppeteer               |
| `npm run test:e2e:run` | Тот же E2E на уже собранном dist                                |
| `npm run format`       | Форматирование исходников, тестов и конфигурации через Prettier |
| `npm run format:check` | Проверка стиля без изменения файлов; также выполняется в CI     |

Отдельный линтер не настроен. E2E сами запускают локальный preview; сценарии проверяют профессии, рабочие действия, переключение приложений, восстановление сохранения и словарь. Актуальное количество и результат тестов следует брать из конкретного прогона, а не из README.

Логи, скриншоты и трассы находятся в игнорируемом каталоге e2e-artifacts/. Условия запуска браузера и независимого OpenCode QA описаны в [QA-workflow](docs/qa-workflow.md). Результаты автоматических проверок не подтверждают работу на всех реальных устройствах.

Prettier использует два пробела, одинарные кавычки, ширину строки 100 и LF. Для VS Code рекомендовано расширение Prettier; настройки проекта включают форматирование при сохранении после его установки.

## Структура и состояние

React, TypeScript, Vite, Zustand и Framer Motion. У игры нет серверного backend или модельных запросов во время игры; OpenCode используется только в процессе разработки.

| Каталог / файл    | Ответственность                                                      |
| ----------------- | -------------------------------------------------------------------- |
| `src/app/`        | Оболочка, настройки и временное состояние интерфейса в uiStore.ts    |
| `src/play/`       | Игровые экраны, ноутбук и их соседние контроллеры/модели             |
| `src/components/` | Общие визуальные компоненты, иллюстрации и иконки                    |
| `src/hooks/`      | Переиспользуемые React-механизмы и общие UI-команды                  |
| `src/utils/`      | Общие вычисления без React-состояния                                 |
| `src/world/`      | Модель мира, переходы, генерация, экономика и сохранения             |
| `src/content/`    | Профессии, сценарии, переводы и заметки об обновлениях               |
| `src/game/data/`  | Исходные определения Frontend-задач, используемые адаптером контента |
| `build/`          | Сборка service worker и проверки сборочных механизмов                |
| `e2e/`            | Постоянные браузерные сценарии                                       |

Компонент использует один соседний контроллер. Общие чистые расчёты находятся в утилитах и моделях, общий React lifecycle — в хуках. Глобальные UI-команды доступны через useAppActions без передачи через промежуточные экраны; локальные формы, фильтры и вкладки конкретного ноутбука остаются у владельцев. Подробные правила — в [AGENTS.md](AGENTS.md).

## Сохранения и PWA

Кампания хранится локально в браузере, отдельно от пользовательских настроек. Общая навигация и открытые окна не сохраняются. Облачной синхронизации нет; разные адреса, включая localhost и 127.0.0.1, имеют отдельные сохранения.

Production-сборка содержит manifest и service worker. После успешного кеширования приложение может запускаться без сети; внешний шрифт при недоступности заменяется системным. Установка зависит от браузера и требует HTTPS либо localhost. Проверка на физическом iPhone/iPad проводится отдельно от desktop E2E.

Обновление доступно в настройках и применяется по действию игрока с сохранением прогресса. Перед пушем повышается GAME_VERSION и добавляются заметки в [src/content/releases.ts](src/content/releases.ts) и [CHANGELOG.md](CHANGELOG.md).

## Локальная аналитика

По умолчанию игровые события не отправляются на сервер. Их можно скачать в настройках; введённые имена, email и произвольный пользовательский текст не входят в разрешённые поля аналитики. Код — [src/world/analytics.ts](src/world/analytics.ts).
