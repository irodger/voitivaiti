# Войти Вайти

Браузерная игра про карьеру внутри IT-компании. Компания, её проекты, сотрудники, отношения и последствия решений сохраняются между рабочими днями и сменами героя.

## Запуск

Node.js 22.12+ и npm. Проверено на Node.js 24.

```sh
npm install
npm run dev
npm run build
npm test
```

Vite показывает адрес локального сервера, обычно http://localhost:5173. `npm run preview` открывает production-сборку из `dist`.

## Игровой цикл

1. Выбери аватар и профессию. Имя и код мира необязательны; имя можно изменить в настройках.
2. Познакомься с компанией: одинаковый seed даёт одинаковые стартовые проекты и проблемы.
3. Начни день с синка, возьми задачу и открой ноутбук на рабочем столе.
4. Работай в IDE, Browser, Console и Chat. Ошибки отнимают время и могут добавлять стресс, но позволяют повторить попытку.
5. Заверши события дня, обсуди повышение во вкладке «Карьера», отдохни дома.
6. На leadership-уровне появляются ревью чужой работы и распределение ресурсов.
7. После завершения событий дня найми следующего героя через «Карьера». Предыдущий сотрудник остаётся NPC; компания и проекты продолжают ту же историю.

Повышение зависит от завершённой работы, профессионального навыка, репутации, общения и карьерного достижения. Следующая управленческая ступень также требует опыта руководства. XP не является единственным условием. Повышение также требует времени в роли и положительного performance review. Рутинные периоды продвигают календарь между значимыми днями. Системные ошибки могут привести к увольнению, стресс 100 — к выгоранию; архив карьер и карта IT сохраняются.

## Контент и мир

- 22 доступные профессии: Frontend, Backend, Mobile, QA, QA Automation, Product Designer, UX Researcher, System Analyst, Business Analyst, Product Manager, Project Manager, Delivery Manager, DevOps, SRE, System Administrator, Security, Data Analyst, Data Engineer, DBA, Solution Architect, Software Architect, L2/L3 Support.
- По два характерных сценария на профессию и два общих сценария руководства: всего 46 шаблонов. Это ограниченный стартовый набор контента; дальнейшие дни переиспользуют его с состоянием текущего проекта.
- Десять архетипов проектов. В компании создаются два проекта с разными стеками, долгом, стабильностью, безопасностью и зрелостью процессов. Культура влияет на накопление долга, процессность — на события согласования, низкая стабильность — на инциденты и блокировки.
- Проблема проекта объединяет работу разных профессий. Исправление и последующая проверка дают разные вклады; вместе они закрывают проблему.
- Временные решения оставляют автора, TODO и историю. Следующий герой видит предшественника и его решения. После завершения текущей задачи можно выбрать другой проект во вкладке «Компания».
- После вводных задач подбор учитывает частоту уже пройденных сценариев, серьёзность общих проблем и оставленные обходные решения. Первые лидерские задания гарантированно знакомят с новым видом работы.

Сохранены FE-1427 и FE-1451. Без ошибок они занимают **227** и **115** игровых минут соответственно. Вопросы и ошибки увеличивают время. В FE-1451 обязательны два клика до исправления и два после него.

## Интерфейс

Desktop — один игровой экран с header, HUD, офисом, рабочей панелью и навигацией. Длинные панели прокручиваются внутри. Mobile использует обычный вертикальный поток.

Ноутбук раскрывается из объекта в офисе через общий Framer Motion layout. Есть края корпуса, камера, нижняя рамка, затемнение офиса и закрытие по Esc. Завершённые шаги доступны только для просмотра, будущие заблокированы. На desktop используются пять состояний курсора; на touch остаётся системное поведение.

RU/EN и clean/adult переключаются в настройках без перезапуска. Маленький перечёркнутый `18+` у логотипа — быстрый переключатель естественных версий реплик. По умолчанию включён clean. Новые термины объясняются при первом обнаружении и сохраняются в словаре персонажа.

## Архитектура

| Каталог | Ответственность |
| --- | --- |
| `src/world/types.ts` | Схема компании, проектов, проблем, героев, карьеры, задач и событий |
| `src/world/simulation.ts` | Генератор с seed, расписание, подбор задач, условия повышения, кандидаты |
| `src/world/engine.ts` | Проверяемые переходы состояния, время, последствия, награды, найм |
| `src/world/store.ts` | Zustand, автосохранение, миграция старой кампании |
| `src/world/analytics.ts` | Локальная аналитика и сменный обработчик событий |
| `src/content/` | Профессии, карьерные деревья, архетипы, сценарии, NPC, термины, переводы |
| `src/content/frontend.ts` | Адаптер сохранённых Frontend-сценариев |
| `src/game/data/tasks.ts` | Исходные определения FE-1427 и FE-1451 |
| `src/play/` | Экраны, ноутбук и повторно используемые игровые механики |
| `src/components/` | SVG-офис, дом, аватары |
| `src/app/` | Оболочка приложения и базовое оформление |

Новая профессия добавляется через описание карьерного пути и ссылки на шаблоны задач. Существующие механики не требуют отдельных веток профессий в React. Новый способ взаимодействия добавляется как тип шага, обработка действия в движке и отображение механики.

Доступны поиск, выбор файла и кода, терминал, ревью, Console, воспроизведение бага, сравнение интерфейсов, анализ журналов/запросов/метрик, планы с порядком действий, связи систем, проверка доступов, release checklist и распределение ограниченных ресурсов.

React + TypeScript + Vite + Zustand + Framer Motion. Без серверного backend и runtime LLM. Изображения локальные SVG. Golos Text загружается из Google Fonts, при отсутствии сети используется системный шрифт.

## Сохранения и правила

`voiti-vaiti-campaign`, schema/version **3**. Предпочтения отдельно: `voiti-vaiti-preferences`. Сохранения локальны для браузера и адреса, поэтому localhost и 127.0.0.1 имеют разные кампании.

Миграция версии 2 переносит героя, показатели, завершённую работу, текущий шаг, попытки, время, число кликов и ожидание ревью. Возврат в ноутбук после reload открывает текущий шаг.

Все действия проверяются движком. Текущий обязательный шаг единственный; completed нельзя наградить повторно, locked нельзя выполнить. Финальная награда атомарно отмечается `rewarded`. Асинхронная проверка сохраняет `running` и оплачивается один раз. Изменения компании и персонажей сохраняются вместе.

## Аналитика и опрос

`trackGameEvent(name, payload)` записывает локальные события старта кампании, профессии, задач и решений, дня, терминов, повышения, найма, смены героя и опроса. Анонимный player ID постоянен в браузере, session ID создаётся при загрузке. Белый список полей исключает введённые имена, email и произвольный текст.

`setAnalyticsSink` позволяет подключить свой обработчик без изменений движка. По умолчанию ничего не отправляется в сеть; последние 1500 событий можно скачать в настройках.

После задачи второго дня появляется явно обозначенный вопрос разработчиков о мобильной версии. «Пропустить» доступно всегда; ответ не меняет игровые показатели и хранится только локально.

## Версия 0.7.0 — первый рабочий день
Имя вводится при встрече с проводником в офисе. Игрок выбирает порядок знакомства с проектом и командой, участвует в коротком созвоне, получает задачу своей профессии и завершает день отдельной сценой. Со второго дня действует обычное расписание.

Состояние знакомства хранится в `Character.firstDay`; новые кампании запускают его, старые сохранения получают завершённое состояние. Компания и продукт используют `projectIntros`, реплики коллег — `teamIntros`, задача выбирается из существующего списка профессии. Термины раскрываются непосредственно в речи по наведению, фокусу или нажатию. Только открытие добавляет запись в `discoveredTerms` и контекст в `termMemories`; автоматического заполнения и угловых уведомлений больше нет.

## Версия 0.8.0 — установка и память имени
Последнее подтверждённое имя хранится отдельно от кампании (`voiti-vaiti-last-player-name`), переживает новую игру и подставляется в сцене знакомства. Игрок может заменить его там или в настройках. Имена существующих сохранений также используются.

Production-сборка содержит manifest, PNG-иконки (включая Apple Touch и maskable) и service worker. Путь установки и offline cache учитывают `/voitivaiti/`. Первая полная загрузка сохраняет приложение и офисную сцену для последующего запуска без сети; при недоступном внешнем шрифте используется системный шрифт. Worker не работает в dev-режиме и не кэширует другие сайты. Обновление устанавливается в фоне и применяется по кнопке в настройках, без внезапного перезапуска активной игры.

Публикация должна работать по HTTPS (localhost разрешён для проверки). На iPhone/iPad: Safari → Поделиться → На экран Домой → открывать как веб-приложение. Имя и прогресс остаются локальными для браузера/установленного приложения и адреса; облачной синхронизации нет. Реальное устройство iOS требует отдельной проверки установки и системных отступов.


## 0.9.0 — работа продолжается между днями

- Junior получает назначенную задачу; выбор очереди и делегирование открываются с опытом и грейдом.
- Незаконченные шаги, очередь, обещания и реакции коллег сохраняются между днями. После основной задачи можно помочь коллегам или оставить работу на завтра.
- Завершение дня проматывает рутину до вечера. Дом использует игровое время; обычный сон снимает 6–12 стресса.
- В HUD остаются деньги и стресс; часы сохраняются. Legacy-поля остаются совместимыми с сохранениями.
- Термины открываются по нажатию поверх текста. Мобильные поля используют минимум 16 px, пользовательский zoom сохранён.
- Исправлена обработка разговоров во время знакомства. Выбор профессионального подхода принимается сразу; проверки фактов показывают наблюдения.

Проверки: targeted unit smoke для диалогов, переноса задачи, сохранений, автономии, последствий и сна; мобильный браузер 390×844 для полей и терминов. Установка PWA и поведение клавиатуры на физическом iPhone требуют отдельной проверки устройства.


## 0.10.0 — стресс, напитки и отпуск

Кофе стоит текущую цену напитка, занимает 15 минут и снимает 11 / 4 / 0 стресса за первый / второй / последующие напитки. Счётчик и напиток дня сохраняются, сбрасываются с новым календарным днём. Контекст перерыва учитывает review, блокер и перегрузку.

Инцидент добавляет 14 стресса, каждые полчаса переработки — 4; сорванные сроки и обещания добавляют нагрузку. Сон снимает 6–12, прогулка 7, игры 5. Управление и результаты технических действий от стресса не меняются.

Отпуск на 3 / 7 / 14 рабочих дней пропускает выходные при подсчёте срока, сохраняет шаг задачи, продвигает проект, очередь и календарные последствия. Зарплата за рабочие дни и бытовые расходы продолжаются; отдельной цены отпуска нет. Итог и история сохраняются. Экономика по-прежнему использует 22 рабочих дня на месячный оклад.

Целевые симуляции: 15 спокойных дней без кофе; инциденты + час переработки + давление срока дают стресс 39 → 57 → 75 → 93 → 100; отпуск из 82 даёт 27 в фиксированном сценарии. Выгорание архивирует карьеру. Проверены сохранения напитка, убывающая отдача и совместимость старого save.
