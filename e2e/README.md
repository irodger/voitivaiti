# Puppeteer E2E: профессии

`npm run test:e2e` собирает игру и запускает проверки в Chrome for Testing.
Нужен Node.js 22.12 или новее.
Браузер устанавливается через `npx puppeteer browsers install chrome`, если установка зависимостей пропустила его загрузку.

Каждая из 22 профессий проходит через настоящий интерфейс:

- создание героя с фиксированным кодом мира;
- имя, проект, знакомство с коллегами и утренняя встреча;
- получение своей первой задачи;
- проверка семейства корпуса и наличия таскбара;
- переход между четырьмя приложениями без расхода игрового времени;
- первое рабочее действие с фактическим изменением progress;
- перезагрузка страницы, сохранение героя, задачи и выполненного действия;
- повторное открытие ноутбука.

Frontend, Backend и QA дополнительно проверяют ноутбук на экране 390×844.
Матрица отдельно проверяет, что не забыта ни одна доступная профессия.

## Запуск

Полный прогон: `npm run test:e2e`.
После уже выполненной сборки: `npm run test:e2e:run`.

PowerShell, выбранные профессии:

```powershell
$env:E2E_ROLES='frontend,backend,qa'
npm run test:e2e
Remove-Item Env:E2E_ROLES
```

`E2E_HEADFUL=1` показывает тестовый браузер; `PUPPETEER_EXECUTABLE_PATH` позволяет указать установленный Chrome.
Это отдельный временный профиль: сохранения вашего обычного браузера не читаются и не меняются.
У каждого теста собственный BrowserContext. Кампания не подставляется и действия не вызываются напрямую через store.
Изоляция контекстов использует [Browser.createBrowserContext](https://pptr.dev/api/puppeteer.browser.createbrowsercontext).
Из localStorage читается результат действий для assertions; перед запуском задаются только язык, тема и отключение звука.

При падении: `e2e-artifacts/<profession>/failure.png` и `errors.json` с ошибкой, браузерными ошибками и тестовым сохранением.
Эти файлы исключены из Git; CI сохраняет их как артефакт.

## Границы покрытия

Это e2e smoke прохождения начала каждой профессии, а не доказательство всей карьеры.
Тест намеренно не выбирает случайные «правильные ответы» для полного прогона.
Длинные причинные цепочки, повышение и найм пока проверяются существующими тестами движка.
Следующее расширение — отдельные явные сценарии завершения задач, ожидания коллег и передачи мира следующему герою.
